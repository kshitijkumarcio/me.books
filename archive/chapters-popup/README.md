# Chapters Popup (Archived)

This folder contains the original Figma-style Chapters popup component (`chapters-popup.tsx`).

### Overview
- Modeled as a Figma frame ("Frame 8") with four corner selection handles and dynamic live dimensions badge (`{width} × {height}`).
- Contained items for:
  - **The Bookshelf** (`books-read`)
  - **Currently Reading** (`current-reads`)
  - **The Wishlist** (`wishlist`)
- Rendered thumbnails (`chapter1a`, `chapter2a`, `chapter3a`) with fading graphic background banners (`chapter1b`, `chapter2b`, `chapter3b`).

### Status
Archived per user request. A new chapters design will replace it.
